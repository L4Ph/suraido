# showcase

A tour of everything suraido.js does, written in suraido.js. Fifteen slides that demonstrate
rather than describe: the reveals reveal, the counter counts, the theme switcher restyles the
deck you are reading, and the votes you cast survive the slide they were cast on.

Deployed from `main` to <https://l4ph.github.io/suraido/>.

```
vp dev
```

`PAGES_BASE` sets the base path for a build served from a subdirectory; the workflow passes
the repository name.
