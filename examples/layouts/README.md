# layouts

Cover, section divider, two columns, ratios, full bleed, quote, figures — the shapes a talk
keeps needing. Made to be copied.

It also shows the other way to write a deck: the slides go straight into `deck([...])` instead
of being named first. Naming them gives the `deck()` call a table of contents and lets one move
to a file of its own, which is what the other examples do; for a short catalogue, the list is
already the table of contents.
